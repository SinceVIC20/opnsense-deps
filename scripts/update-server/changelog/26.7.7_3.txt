This release comes from the temporary, unofficial Mono Gateway update server at mono-opnsense.sincevic20.com, not from OPNsense or Mono. It brings the whole system up to OPNsense 26.7.7.

- release: the OPNsense GUI and plugins move from 26.7.3_8 to 26.7.7, with all of OPNsense's fixes from 26.7.4 to 26.7.7; the dashboard now shows 26.7.7
- system: third-party packages updated to the OPNsense 26.7.7 versions
- kernel + system: FreeBSD 15.1-RELEASE-p4 security and errata fixes (sysvsem, kqueue, jail, ktls, OpenSSL, syslogd, time zone data)
- firmware: the safe-upgrade checks now install with a normal GUI update, so routers set up before 14 October 2026 get them without running the one-line shell command again
