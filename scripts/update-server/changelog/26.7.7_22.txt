date: 2026-11-05
This release comes from the temporary, unofficial Mono Gateway update server at mono-opnsense.sincevic20.com, not from OPNsense or Mono. It fixes a crash when the temperature is read by several programs at once, offloads PPPoE on VLANs named like vlan0.7, keeps the Traffic Graph wide enough for its header, and makes rolling back and copying the configuration from an older install more reliable.

- system: reading the temperature sensors from several programs at the same time, for example a script while the dashboard is open, no longer crashes and restarts the router.
- dashboard: the Traffic Graph widget can no longer be made so narrow that the in and out rates cover the title and the In/Out key.
- updates: rolling back to the previous kernel now also puts back the offload files that ran with it, so the two match again.
- updates: copying the configuration from an older install in Recovery Linux now recognises a UFS partition, and a router that was stuck restarting before the flash no longer tries a rescue on the new image's first start.
- interfaces: PPPoE on a VLAN whose device name has a dot, such as vlan0.7 for Telekom's VLAN 7, is now offloaded instead of all its traffic staying on the CPU.
- interfaces: choosing a fixed 1000baseT speed for a copper port now gives a working full-duplex link instead of half duplex, which the port can't run.
- interfaces: the copper ports no longer offer Energy Efficient Ethernet, which made the link drop for a few seconds under traffic with some switches, such as the MikroTik CSS610.
