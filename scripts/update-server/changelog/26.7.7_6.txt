This release comes from the temporary, unofficial Mono Gateway update server at mono-opnsense.sincevic20.com, not from OPNsense or Mono. It fixes offloaded traffic on a second WAN, adds a Mono Gateway box to the dashboard that shows the release and whether hardware offload is working, and stops the router from dropping hardware notices during bursts of short connections.

- multi-WAN: offloaded traffic that leaves through a second WAN, because of a gateway set on a firewall rule or a gateway group, now uses that WAN's own gateway instead of the default one. It no longer stops when offload is on. Replies to port forwards on a second WAN are fixed the same way. Feedback from multi-WAN setups is welcome.
- offload: more room to queue hardware notices, so a burst of short connections ending at once no longer drops some of them.
- dashboard: a new Mono Gateway widget shows the release, whether hardware offload is on and which update server is in use. It is added to the dashboard once, after the restart. The login message now shows the release too, and cmm, the hardware offload service, can be started and stopped under System > Diagnostics > Services.
